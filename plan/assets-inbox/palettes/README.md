# Palette reference data

`top-100-three-color-combinations.json` is a verbatim structured extraction of the ranked `palettes` array from the source visualization linked in that file. Its order is approximate popularity rank; colors are the exact dominant/support/accent hex values, intended for a 60/30/10 distribution.

Use this as a reusable reference pool for ship recoloring, coach/editor cosmetics, and future reward-palette selection. It is not an unlock registry or production ID list. Review chosen palettes and assign stable production IDs separately; do not replace existing palette IDs or expose all 100 as unlocked choices by default.
