# Reward canister

`canister.glb` is a browser-ready conversion of the user-supplied `1-kettlebell-3d-model.zip` / `tripo_convert_d1d88121-1e13-4450-b625-ef77c4dcac90.fbx`, made with Blender 4.5.10. The source FBX is retained in the task attachment. The pack opener renders this model at 64 × 64 pixels and scales it with nearest-neighbor filtering.
