The app icons use the user's original purple MYR5 artwork from the Mom Inc website:
https://github.com/MomInc-MBS/mominc-mbs.github.io/blob/main/tv/assets/myr5-purple.png

myr5-original.png is an unchanged copy of that asset. scripts/icons.mjs fits it onto square icon canvases without cropping or redrawing the character. The maskable version adds space for phone icon shapes. The coach-192.png and coach-512.png files are compatibility copies for older links.
